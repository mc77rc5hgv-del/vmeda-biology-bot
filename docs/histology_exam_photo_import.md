# Фотографии экзаменационных препаратов

Привязывайте каждый проверенный кадр к ID действующего перечня. Номер из файла, порядок вложений и название без уточнения окраски или стадии могут относиться к разным карточкам. Сверяйте подпись и видимые признаки. Если соответствие неоднозначно, оставьте фото до проверки. Несколько проверенных ракурсов одного препарата получают один ID препарата. Его положение в перечне и учебный прогресс сохраняются.

Бот и API читают `histology_exam_photo_catalog.json`. В экзаменационной карточке сохраняются прежние изображения и протокол, к ним добавляются снимки с текстом их собственных подписей. В тренажёре выбор препарата остаётся по его ID, а один из доступных ракурсов выбирается при выдаче вопроса. Подпись относится к показанному кадру и открывается после ответа.

## Подготовка партии

1. Положите исходные фотографии и файл описания в одну папку. Оригиналы храните отдельно от репозитория.
2. Сверьте ID по действующему каталогу командой `python -m scripts.import_histology_exam_photos --list`.
3. Сохраните проверенные соответствия в UTF-8 JSON. Например:

   ```json
   {
     "photos": [
       {
         "specimen_id": "d3_11",
         "file": "photo_01.jpg",
         "caption": "Текст подписи к снимку",
         "quiz": true
       }
     ]
   }
   ```

4. Используйте `"quiz": true`, когда сам снимок подходит для распознавания и по надписям на нём нельзя прочитать ответ. Если на фото видна подпись с ответом, укажите в `quiz` имя отдельно проверенного кадра или обрезанной версии, сохраняющей диагностические признаки. Если подходящего варианта пока нет, опустите поле `quiz`: этот кадр будет доступен в карточке.
5. Запустите `python -m scripts.import_histology_exam_photos batch.json` и сверьте отчёт. После проверки повторите с флагом `--apply`. Команда сохраняет ориентацию, убирает метаданные, оставляет исходники в их папке и не переписывает существующие привязки при повторном импорте.
