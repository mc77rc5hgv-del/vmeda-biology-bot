# Тестовый доступ miniapp

Главный администратор: `/admin` → «Выдать тестовый доступ miniapp» → `@username`.
Пользователь должен сначала нажать `/start`, чтобы бот знал его текущий username.
Допустим также Telegram ID уже зарегистрированного пользователя. Регистр username не важен.
Старая запись username, не совпадающая с текущим username пользователя, отклоняется.

Доступ бессрочный до отзыва: `/admin` → «Отозвать тестовый доступ miniapp» → `@username` / ID.
Список активных тестировщиков доступен там же, по 25 на странице.
После выдачи Telegram получает постоянную кнопку «VMEDA App» рядом с полем ввода.
Кнопка также доступна в новом главном меню (/start) и через /app.
При запуске бота восстанавливаются кнопки всех ранее выданных активных тестировщиков;
после отзыва постоянная кнопка возвращается к меню команд.
Смена username не теряет доступ: ключом служит стабильный Telegram ID.
В карточке пользователя и профиле miniapp отображается статус тестировщика.

В miniapp доступны существующие учебные разделы, билеты, материалы, медиа, зачёты и AI
без тарифной квоты. Глобально закрытые на переработку предметы не открываются;
техрежим анатомии доступен тестировщикам для проверки существующих модулей.
Сохраняются ограничения конкурентности AI, автовыключатель расходов и учёт использования.
Реальные платежи не симулируются и не подтверждаются тестовым статусом.

Права проверяются сервером при каждом запросе, включая вход при `admin_only`.
После отзыва учебные права возвращаются к обычным подпискам/рефералам;
при закрытой бете существующий токен тестировщика получает 403.
Это не роль администратора, не платная подписка и не ручной доступ ко всему боту.

Данные хранятся в новом поле stats `miniapp_tester_access`, по Telegram ID.
История выдачи/отзыва, время, администратор и username на момент действия сохраняются.
Старые подписки, платежи, пользователи и учебная статистика не удаляются и не меняются.
